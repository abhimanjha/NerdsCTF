# User Guide: nerdCTF - Version 1

Welcome to **nerdCTF**! This guide assists cybersecurity students and players in starting their training journey on the platform.

---

## 1. Registering an Account
1. Open `http://localhost:3000` in your web browser.
2. Select the **Register** button in the top right corner.
3. Fill in your email address, select a unique username, and choose a strong password.
   - *Note: Password must contain at least 8 characters, an uppercase letter, a number, and a special character.*
4. Select **Create Profile** to initialize your account.

---

## 2. Navigating the Dashboard
Once logged in, the **Dashboard** displays your profile metrics:
- **Total Points**: Sum of points from solved challenges.
- **Global Rank**: Your real-time position on the scoreboard.
- **Solved Categories**: Chart showing distribution of solved categories.
- **Unlocked Badges**: Earned profile badges.
- **Recent Activities**: A feed displaying your solved challenges history.

---

## 3. Exploiting Challenges (Labs)
1. Select the **Labs** tab in the navigation bar.
2. Choose from the available challenges (categorized as Easy, Medium, or Hard).
3. Select **Enter Lab Workspace** on the challenge card.
4. Review the Description and **Learning Objectives** on the left.
5. Click **Launch Target Machine**. This opens the target server in a new browser tab.
6. Attempt to exploit the target system using the skills outlined in the academy lessons.
7. Capture the flag string (format: `nerdCTF{...}`).
8. Return to the workspace page, enter the flag in the submission form, and click **Submit Secret Flag**.
9. If correct, points are added and a solved badge is earned.

---

## 4. Using the Academy
1. Select the **Academy** tab in the navbar.
2. Navigate topics and lessons in the left sidebar.
3. Read the lesson markdown contents inside the viewer.
4. Answer practice quizzes at the bottom of the page to reinforce the concepts.
5. Click **Mark Lesson Complete** to track your syllabus completion. Complete all lessons to unlock the **Academy Scholar** badge.

---

## 5. Support Tickets
If you find bugs, have requests, or need admin support:
1. Navigate to the **Support** tab.
2. Submit general feedback in the left column.
3. Or open a private support ticket using the right-side form. Monitor your ticket status directly inside the portal.
